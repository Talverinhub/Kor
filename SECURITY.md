# Security

Please don't report security problems in a public issue. Email talverincontact@gmail.com with what you found and how to reproduce it. I'll reply as soon as I can.

This matters most for anything touching updates, the TalverinConnect connection or stored Spotify logins. Only the latest release gets fixes.

## Türkçe

Güvenlik sorunlarını herkese açık bir sorun olarak bildirme. Ne bulduğunu ve nasıl tekrar edildiğini talverincontact@gmail.com adresine yaz. En kısa sürede dönerim.

Bu özellikle güncellemeler, TalverinConnect bağlantısı ve saklanan Spotify girişleriyle ilgili konular için önemli. Düzeltmeler yalnızca son sürüme gelir.
