# Changelog

## 1.0.5.1

- TalverinConnect is now on the Chrome Web Store. Install TalverinConnect opens the store page
- The store version connects without an approval prompt. Manual install is still available

## 1.0.5.0

- Four themes in Settings, General: Kor, Lavender, Focus (ADHD) and Extreme
- Focus shows one task, a large time and progress in five parts while the timer runs
- Extreme adds a neon dial, combos, points, levels, a daily streak and celebrations

## 1.0.4.0

- Notes with tabs, formatting and colors. They attach to the side of Kor or the top of the mini timer
- Checklists, search, and Ctrl+Z to bring back a deleted note
- The note for your "What are you doing?" topic comes to the front when the timer starts
- Ctrl+Shift+Alt+N opens notes from any app
- The mini timer stays in front of the taskbar and inside the screen

## 1.0.3.1

- Clearer wording in the Turkish interface
- Removed an old announcement and unused code

## 1.0.3.0

- English interface. Kor follows your Windows language, and you can change it in Settings
- New guided tour that highlights each part of the app
- Your own Spotify Client ID can be entered in Settings
- The app file is now called Kor.exe
- TalverinConnect, an optional browser extension for YouTube Music. It uses the same language as Kor
- Kor is now open source under the MIT License

## 1.0.2.1

- The dial reacts to the bass of Spotify music

## 1.0.2.0

- Stopwatch and song-count timer
- Topics and daily goal ring
- Finish and quick start in the mini timer
- Timer protection, safer updates and new hotkeys
